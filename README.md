What your project is and how to use it: my project is a pair of 3d printed bluetooth headphones, you can use it too listen to music or listen to anything else.
Why you made it: i made these because I've always wanted the best audio quality, and up to a certain point that is subjective, being able to choose my own Bluetooth chip, what shell materials, the shell shape, the infill on ther parts for dampening etc gives me full control over the audio, so ive been really exited to do this project!
